# AI Workplace Productivity Hub

## Overview

AI Workplace Productivity Hub is a responsive web application that combines multiple AI-powered productivity tools into a single dashboard. The platform is designed to help professionals automate common workplace tasks, improve efficiency, and enhance decision-making through an intuitive user interface.

This project was developed as part of an AI-powered productivity application assignment using **Lovable AI**.

---

## Features

* **AI Task Planner & Scheduler**

  * Prioritizes tasks
  * Generates smart daily schedules
  * Provides productivity recommendations

* **AI Research Assistant**

  * Summarizes research topics or text
  * Extracts key insights
  * Generates actionable recommendations

* **AI Workplace Chatbot**

  * Interactive AI assistant
  * Personalized onboarding
  * Context-aware responses based on user profile

* **Customizable Appearance**

  * Light, Dark, and System themes
  * Five selectable accent color themes
  * Theme preferences saved locally

* **Responsive Dashboard**

  * Sidebar navigation
  * Mobile-friendly layout
  * Modern and accessible UI

## Getting Started

### Prerequisites

* Node.js (v18 or later)
* npm

### Installation

```bash
git clone <https://github.com/Que-Jr/work-genie-hub.git>
cd <work-genie-hub>
npm install
npm run dev
```

Open your browser and navigate to the local development URL displayed in the terminal.

---

## AI Integration

The application is designed to support integration with an AI service such as the OpenAI API.

If an API key has not been configured, the application displays sample AI responses for demonstration purposes.

---

## Responsible AI

This application is intended to assist users with workplace productivity. AI-generated content should always be reviewed before being used for business decisions. Users should avoid entering confidential, personal, or sensitive information into AI prompts.
